## 🏛️ System Overview

## 🛠️ Frozen Tech Stack MVP

* **Database:** PostgreSQL + SQLAlchemy + Alembic
* **Orchestrator:** Docker Compose & Nginx
* **AI Engine:** Gemini API
* **Channel Adapters:** Web & Telegram
