# BoonTrack Domain Glossary

| Istilah | Definisi |
| :--- | :--- |
| **Goal** | Tujuan utama pengguna (contoh: `GET_JOB`). |
| **Intent** | Maksud spesifik yang merupakan turunan dari Goal (contoh: `CREATE_CV`). |
| **Knowledge** | Peta semantik RAG (keywords, alias, synonyms, weight) untuk mencocokkan input pengguna. |
| **Digital Asset** | Solusi nyata yang terkurasi (PDF, Docx, Template) yang dikirim ke pengguna. |
| **Solution Engine** | Orchestrator inti backend yang mengolah permintaan pengguna hingga menghasilkan solusi. |
| **Delivery** | Mekanisme pengiriman aset dan pembentukan shortlink. |
| **TTS (Time to Solution)** | Metrik kecepatan penyampaian solusi ke pengguna (< 60 detik). |
| **FSR (First Solution Rate)** | Metrik ketepatan solusi pertama yang diberikan sistem (> 85%). |
